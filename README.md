# Game Hangar

Free browser games: **Skyward Aces** (WWII newsreel dogfighting), **Night Orbit** (night gunship), **Scrap Tower** (arcade foundry climber), **QuickScope Ops** (tap-to-quickscope sniper waves) and **Sideways Club** (3D street drifting).

Sideways Club's engine, skid and impact sounds come from Kenney's Starter Kit Racing (CC0); the skid sound is by Landeplage (CC0).

Play at https://delnoa98.github.io/games/
